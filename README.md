## Engineering approach

```text
Problem framing → Data → Experiments → Evaluation → Product integration → Reliable delivery
```

I prefer systems that are:

- **Outcome-driven** — built around a real user or business problem
- **Evidence-based** — evaluated with clear assumptions and measurable checks
- **Maintainable** — understandable code, explicit boundaries, and useful documentation
- **Responsible** — privacy, security, and failure modes considered from the start
- **Operational** — tested and deployable beyond a notebook or prototype
